# Study 2 – Resistance, Cooperation, and Reliability Judgments

This repository contains the preregistration, simulation code, and analysis plan
for **Study 2**, which investigates how experimentally manipulated resistance
and scenario severity influence interviewers’ judgments of reliability, loyalty,
and vulnerability in a simulated security interview context.

The preregistration was finalized prior to data collection and analysis.
A tagged release (`v1.0`) marks the locked preregistration.

## Repository structure

- `prereg/` – preregistration documents (design, hypotheses, analysis plan)
- `scripts/` – simulation, balance checks, and analysis code
- `outputs/` – reserved for model outputs (empty at prereg stage)

## Status

- Preregistration: **Locked (v1.0)**
- Data collection: Planned
- Analysis: Not yet conducted
